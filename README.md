# Древо Любарского

Трёхмерное «Древо» тем эфиров: ствол — время, ветви — темы и созвездия, листья — фрагменты роликов.
Клик по листу открывает ролик с нужной секунды. Живая версия: https://momendex.quest/tree.html

Это копия страницы вместе с данными (снимок на 3 октября 2026 года) из проекта Momendex.

## Состав

| Файл | Что это |
|---|---|
| `tree.html` | страница |
| `tree/tree.js` | программа отрисовки (three.js подгружается из интернета, с jsDelivr) |
| `tree/data/tree.json` | подписи, цвета, годы, скелеты ветвей, список роликов |
| `tree/data/leaves.bin` | листья: положения в трёх видах («дерево», «куст», «цилиндр»), тема, созвездие, ролик, секунда |
| `tree/data/search_words.json`, `tree/data/search.bin` | указатель слов для поиска прямо на странице |

## Как открыть

Двойным щелчком по `tree.html` страница не заработает: браузер не даёт ей читать файлы данных с диска.
Нужен любой простой веб-сервер, например:

```bash
python -m http.server 8000
```

затем открыть http://localhost:8000/tree.html

Или включить GitHub Pages для этого репозитория (Settings → Pages → ветка `main`, папка `/`),
и «Древо» будет открываться по адресу вида `https://<имя>.github.io/<репозиторий>/tree.html`.

## Что зависит от внешнего сервера

- **Поиск по словам** работает целиком внутри страницы.
- **Поиск по смыслу** отправляет запрос на `https://momendex.quest/v8/search`. Без доступа к этому серверу
  он не сработает, остальное «Древо» — сработает.
- Ролики открываются через YouTube.

Данные — снимок: сами по себе они не обновляются. Новые эфиры появятся здесь только после новой выгрузки
из основного проекта.
